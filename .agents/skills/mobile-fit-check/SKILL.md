# Mobile Fit Check

Use this skill for final mobile sanity checks.

## Focus areas
- 390px-class viewports first, then desktop confirmation.
- Primary actions remain reachable without awkward scrolling.
- Bottom tabs do not obscure content.
- Input fields and chat composers keep adequate spacing when focused.
- Dense data blocks still scan cleanly on small screens.

## Guardrails
- Prefer wrapping or stacking over shrinking text into unreadability.
- Keep icon buttons at stable touch sizes.
- If a screen is too long, make section order and action priority obvious.
