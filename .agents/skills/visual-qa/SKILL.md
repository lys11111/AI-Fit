# Visual QA

Use this skill before signing off on AI-FIT UI work.

## Checklist
1. Run the relevant visual tests.
2. Check the screen at desktop and mobile widths.
3. Look for clipped text, overlapping layers, unstable buttons, weak contrast, and overused accent color.
4. Verify primary actions stay visible and clear in the first viewport.
5. Confirm bottom navigation and route headers communicate state correctly.

## Output style
- Report concrete defects first.
- If no defects are found, mention remaining test gaps or residual risk.
